# API Контракты

## Целевой контракт префиксов

В проекте зафиксированы три обязательных входных префикса API:

- `/api` — базовые (legacy/core) эндпоинты, включая healthcheck.
- `/api/v1` — versioned API (v1).
- `/reports` — отдельный поток генерации и получения отчётов.

Любые непредусмотренные дубли без этих префиксов (например, `/health`) не считаются частью целевого контракта.

## Базовые маршруты

### GET `/api/health`

```json
{
  "status": "ok"
}
```

### POST `/reports/generate`
Создание задачи генерации отчёта.

### GET `/reports/{report_id}`
Получение статуса ранее созданного отчёта.

### `/api/v1/*`
Versioned ресурсные маршруты (например, `/api/v1/reports`).
